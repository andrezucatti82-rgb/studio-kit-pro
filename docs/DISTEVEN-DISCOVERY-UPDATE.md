# Navegação segmentada, tipografia e descoberta

O menu superior usa a mesma superfície escura arredondada do seletor Explicar/Apresentar/Vender. A categoria atual tem preenchimento amarelo-limão e texto escuro; as sete opções continuam visíveis no celular. Os submenus continuam em fluxo e alinhados ao começo das categorias.

A interface utiliza uma escala por função: 12 px para metadados, 14 px para navegação compacta, 16 px para controles e leitura, 20 px para seções e 28 px para títulos de página no celular.
